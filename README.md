## 快速开始

### 1. 导入许可证

首次使用需要导入许可证文件（`.sbl` 格式）：

1. 打开应用，进入**设置**页面
2. 点击**导入许可证**按钮
3. 选择许可证文件

> ⚠️ 许可证文件创建后 **1 小时内** 必须导入，超时将无法使用

### 2. 配置机台狗号

在设置页面填写机台狗号（clientId）。区域、店铺 ID、店铺名称和认证时间由 APP 执行 ALL.Net PowerOn 后自动获取并缓存，设置页只读显示。

- 未输入狗号时，输入框只展示 **11 位格式模板**（`A63E01XXXXX`），不会显示真实狗号示例；模板只是占位提示，不代表默认值。
- 狗号必须是**恰好 11 位 ASCII 字母或数字**；输入中的字母即时转为大写，保存和读取时也统一使用大写值；首尾空白自动清理，内部空白及其他字符会被拒绝。
- 如果 PowerOn 返回狗号失效，APP 会阻止后续 Title 通信。

设置页的“账号数据管理”会列出本地保存的账号及数据记录数，删除入口位于对应账号行。

### 3. 开始使用

应用底部有三个标签页：

- **发送功能票**：扫描二维码 → 自动登录 → 发送功能票 → 自动登出
- **获取账号数据**：“修改并上传”主开关关闭时仅获取数据；开启后显示“批量上传歌曲”子开关，可选择普通自定义配置或批量上传歌曲流程
- **个人数据**：浏览已保存的账号、收藏品和歌曲数据，并使用查分器同步

操作步骤：

1. 点击**扫描二维码**或**手动输入**
2. 扫描/输入公众号生成的二维码，或复制其网页链接（支持自动读取剪贴板）
3. 等待自动处理完成（处理中显示进度和实时日志）
4. 查看日志确认结果（支持导出诊断日志）

## 功能说明

### 时间同步与 PowerOn 状态

主界面左上角显示 NTP 时间同步和 PowerOn 的合并状态：

| 图标 | 颜色 | 说明 |
| -- | -- | -- |
| ✓ | 🟢 绿色 | NTP 同步成功，且 PowerOn 已完成本次实时认证 |
| ⏱ | 🟠 橙色 | 正在进行 NTP/PowerOn 检查，或已安全复用当日 PowerOn 缓存（可继续执行） |
| ✗ | 🔴 红色 | NTP 不可用、PowerOn 失败，或狗号失效 |

- 应用启动时统一完成设置加载和首次 PowerOn，不会并行重复发起。
- PowerOn 完整缓存按“机台狗号 + 当天 07:00 游戏日”保存；同一天命中完整记录时直接复用，不再重复请求。已安装用户升级后，本地数据库会自动迁移并修复历史缓存，无需清除应用数据或重填狗号。
- 只有 NTP 已同步且可信时间有效时，APP 才会进行软封禁记录维护等需要可信时间的操作；未同步时保持安全拒绝。
- 同步或 PowerOn 检查期间不能点击执行或扫描二维码。

### 二维码处理

支持**扫描二维码**（需相机权限）和**手动输入**（支持自动读取剪贴板）两种方式。

- 剪贴板既支持二维码字符串，也支持公众号生成的网页链接；链接会从文件名提取二维码内容，查询参数不参与。
- 二维码有效期为 **10 分钟**，超时需重新获取。

输入二维码后，输入框下方会显示剩余有效期倒计时，颜色随剩余时间变化：

| 颜色 | 含义 | 可提交 |
| -- | -- | -- |
| 🟢 绿色 | 剩余 ≥1 分钟，正常有效 | ✓ |
| 🟠 橙色 | 剩余 <1 分钟，临近过期 | ✓（请尽快提交） |
| 🔴 红色 | 已过期 | ✗ |
| ⚪ 灰色 | 格式无效或未输入 | ✗ |

### 功能票倍数

仅在「发送功能票」标签页可调整：

| 倍数 | 价格 | 安全性 |
| -- | -- | ----- |
| 2倍 | 1 | ✅ 安全 |
| 3倍 | 2 | ✅ 安全（默认） |
| 5倍 | 4 | ⚠️ 危险 |

> ⚠️ 5 倍功能票存在风险，请谨慎使用。4 倍和 6 倍因游戏版本 1.55 起不再支持，已移除。

### 发票处理

- 发票等待固定为 **20 秒**，从登录成功返回后开始计时，无需配置。
- 账号已有功能票时会自动跳过发票；没有功能票时在等待结束后发送发票。
- 发票会静默保存本次读取的账号数据到本地，库存只在本轮使用；保存失败不阻断流程。
- 发票结果未知时只会安全对账确认，不会重复发送。

### 许可证系统

- **普通用户许可证**：仅限许可证中列出的 UserID 使用，可使用全部功能（含批量上传歌曲）
- **管理员许可证**：不限制 UserID，可使用全部功能
- **试用许可证**：仅允许绑定 1 个 UserID，从签发时刻起固定有效 `2880` 分钟（两天）；可使用发票、获取账号数据和普通自定义修改上传等，但**不允许使用批量上传歌曲**
- 普通用户/管理员许可证支持永久有效或自定义限时有效；试用证有效期不可修改
- 所有许可证创建后须在 1 小时内导入；试用证的导入时效不会顺延其两天有效期

### 自动更新与公告

- 进入**设置**点击**检查更新**，也可开启**自动检查更新**。
- 更新检查、APK 下载和远程公告均使用设备信任的 TLS 证书链；证书无效会被拒绝。
- 下载时会先显示下载源选择窗口，只列出可用源；窗口只显示固定的源名称、可用状态和延迟，不显示具体域名、端口或错误文本。选定源后不会静默切换其他源。
- 若发现更高版本但该 Release 尚未提供 APK，会明确显示“新版本安装包尚未上传，请稍后再试”，不会误报已是最新版。
- 版本更新后首次打开应用会弹窗展示更新内容；跨多版本升级时会累积展示全部未查看更新内容。
- 更新与公告服务按应用内配置的 CDN、自建源和直连回退源访问，**不会读取或注入系统 WLAN 代理**。

### 日志与诊断导出

- 日志面板实时显示操作日志，支持信息/成功/警告/错误四级别。
- 点击**导出**可保存完整诊断日志（`.txt`），包含本次实际使用的应用配置/设置/运行状态、操作日志、变更详情、最近 10 批 UserLog/UserAll 上传载荷，以及 GameClient/LXNS 网络诊断详情。
- 载荷只来自实际发送前的请求体，按批次成组保留最近 10 批，超限自动淘汰最早批次，控制长时间任务的内存占用。
- LXNS 诊断正文单次最多采集 10 KiB，文件中会标注总量与截断量，便于反馈网络问题。

### 获取账号数据

第二个标签页以“修改并上传”（默认开启）为主开关，“批量上传歌曲”（默认关闭）是同一卡片内的子开关：

- **主开关关闭**：隐藏并清除批量上传歌曲子开关；仅获取数据并登出，不修改存档
- **主开关开启、批量上传歌曲关闭**：获取数据 → 普通自定义配置 → 上传存档 → 登出
- **主开关开启、批量上传歌曲开启**：仅普通用户/管理员许可证可用；登录并获取完整账号数据 → 批量上传歌曲配置 → 分批处理 → 续关回验

试用许可证下会显示“批量上传歌曲”子开关及购买说明，但开关保持关闭且不可操作。

#### 批量上传歌曲

批量上传歌曲是普通用户/管理员许可证专属功能。配置页的**操作模式互斥**：

- **批量上传歌曲**：把未达到目标的谱面分批写入目标成绩
- **歌曲成绩清除**：把已有成绩清为固定 0 分字段（见下节）

**目标选择方式互斥**：

- **按版本选择**：处理一个或多个版本的并集，多版本取并集去重
- **按歌曲选择**：只处理多选器明确确认的 `musicId`，不会扩展到同版本其他歌曲，也不设置 30 首上限

两种方式都把所选难度（绿/黄/红/紫/白）应用到目标歌曲。

**批次与额度**：每批按普通模式的 3 个短曲额度切分。短曲消耗 1 个额度；歌曲目录标记为长曲的消耗 2 个额度（长曲只生成 1 条真实成绩）；真实歌曲不足额度时用虚拟 Playlog 补齐。长曲可与一首短曲同批，两首长曲拆成两个批次。

**成绩条件**：

- Achievement：留空时无/FC/FC+ 默认下限 `1000000`，AP/AP+ 默认下限 `1005000`，上限默认 `1010000`；只要求下限严格低于上限。选择 AP 时下限不得低于 `1005000`（含边界），选择 AP+ 时上限必须为 `1010000`。
- DX 百分比：默认 `75%..90%`，支持 `0.00%..100.00%` 最多两位小数，表示本次实际成绩下连续可达 DX 区间的位置，`0%`/`100%` 对应两端。
- 已有成绩按 `无 < FC < FC+ < AP < AP+` 判断是否达标；新生成成绩精确保持所选 combo，不会自动升降级。

**历史成绩保护**：写入已有谱面时，Achievement 与理论次数不会低于历史值，Combo/Sync 按较高等级保留，DX 按配置窗口判断——窗口内保留、低于下限才提升、高于上限且无法承载时才受控降到窗口上限。只有“歌曲成绩清除”模式允许固定字段降级。

#### 歌曲成绩清除

- 只处理本账号完整数据中**已经存在**的 `(musicId, level)`，不会为未游玩谱面造记录。
- 每条成绩严格写入 `achievement=0`、`comboStatus=0`、`syncStatus=0`、`deluxscoreMax=0`、`scoreRank=0`、`extNum1=0`、`playCount=1`。
- LXNS 明确返回 HTTP 404 时跳过整首并保留原成绩，其他异常安全停止。
- 虚拟补位记录不属于清除目标；普通/管理员许可证、confirmed 登出、续关和完整数据回验规则不变。

**歌曲成绩上传补充**：

- 每行必须选择实际存在的 `musicId` 和难度；同一列表禁止重复 `(musicId, level)`。
- “3track”是 **3 个短曲额度**，不是固定 3 条成绩。短曲消耗 1、长曲消耗 2；不足额度时用虚拟 Playlog 补齐，最终 Playlog 数量与实际建立的成绩一致。
- `playCount` 留空时使用原始次数 +1（无原始成绩为 1）；理论次数仅在最终 `1010000 + AP+` 时可编辑。
- 开启“Playlog 真实化”后，配置页按谱面物量准备判定：先按 Achievement 与 Combo 生成基础判定，再调整可达的普通键判定匹配 DX，Slide 不计入可达区间；最终上传直接复用配置页已保存的判定值。关闭真实化时使用旧兼容模板，仍可配置娱乐用判定值。
- 手动填写判定与自动结果共用同一套上传路径，不会在上传前重新求解。

### 数据页面

第三个标签页提供账号数据浏览和收藏品/歌曲查询：

- **账号页**：展示用户信息、DX Rating、游玩统计、当前装备；顶部账号信息卡片显示当前 DX Rating，游玩统计只保留最高 DX Rating，并在友人对战段位后追加显示段位认定段位文字。账号预览窗和游玩统计窗之间提供查分器同步入口（水鱼同步 / 落雪同步）。
- **收藏品查询**：按种类浏览头像、姓名框、背景、称号、搭档的 ID、名称和图片，支持按持有状态筛选；已持有项显示库存，旅行伙伴显示当前等级；详情展示来源表中已知的获取来源（含引用明细）。
- **歌曲查询**：按分类（标准/DX/宴会会场）和版本筛选歌曲，查看谱面物量、理论 DX 分和游玩成绩 DX 分；标准谱、DX 谱和宴会场谱互不混用，版本按当前谱面收录版本分类。

**搜索空白名称**：搜索框输入普通空格或全角空格时，会筛选名称为空或全空白的合法项目。例如 `musicId=11422` 的歌曲与对应 AP 称号 `titleId=258147` 的目录值都是单个全角空格，不是空字符串；它们都能通过 ID 或空白查询定位，属合法目录项而非无效歌曲。

**查分器同步**：

- **水鱼同步**：上传本地成绩至水鱼查分器，需在数据页输入 Import-Token（首次），再次同步时确认记录数后上传；宴会场歌曲自动跳过；Token 失效自动清除绑定。
- **落雪同步**：上传本地成绩至落雪咖啡屋，需输入个人 API 密钥；原生支持宴会场曲目；密钥失效自动清除绑定。
- 删除账号数据时会同步删除对应查分器绑定。

### 日志面板

- 实时显示操作日志，支持四种级别；日志保持独立滚动。
- 大字体/大显示大小下主页面会自动切换紧凑布局：二维码输入区始终保持可编辑，输入框压缩为单行并支持横向滚动；扫描按钮显示为“扫码”，并与执行/取消按钮保持同一行。
- 发票倍率、账号模式等低频功能选择区默认收起，点击整条标题/摘要栏即可展开/收起，收起时摘要与标题、图标整体垂直居中，并带平滑动画。
- 空日志状态在内容区整体居中；空间不足时图标与文案横向并排。
- 日志内容完整显示，不会为增加可见条数而截断名称、ID 或错误详情。

### 操作反馈

应用内所有提示消息（如“已保存”“二维码已过期”）新显示时立即替换上一条，避免旧消息滞留。

### 取消操作

处理过程中可点击**取消**，应用会在下一个安全检查点停止主业务并尝试登出；若登出无法确认，Session 会保留，供下次手动执行时收尾。取消发生在登录响应返回窗口内时，APP 会先保存收到的 Session 再登出，避免服务器已登录而本地没有会话可清理。

### 当前执行保护

- 开始处理前会确认 Android 前台服务已启动；未启动则不继续业务。
- 前台执行时保持当前页面不自动息屏；按 Home/切应用/锁屏后屏幕可正常关闭，前台服务继续维持执行所需 CPU。
- 系统强制杀 APP 或从最近任务划掉后不会自动续跑；下次手动执行时用数据库中的 Session 尝试收尾旧会话。

### 异常退出自动登出

登录成功后先确认 Cookie 已保存到本地，再进入后续业务。只有服务器明确确认登出才删除 Session；登出无法确认或 APP 意外关闭时保留 Session，供下次手动执行收尾。该机制只清理会话，不会自动恢复已中断的发票或上传。

## 常见问题

### Q: 提示“二维码已过期”
**A:** 二维码有效期为 10 分钟，请在公众号上获取新的二维码。

### Q: 提示“许可证不允许操作此用户ID”
**A:** 当前许可证未包含您的 UserID，请联系管理员授权或使用管理员许可证。

### Q: 提示“许可证导入时效已过”
**A:** 许可证文件创建后 1 小时内必须导入，超时请联系管理员补发。

### Q: 提示“许可证已过期”
**A:** 许可证已超过有效期，请联系管理员续期或重新获取。

### Q: 为什么试用许可证不能开启批量上传歌曲？
**A:** 试用证仅绑定 1 个 UserID，固定有效 2880 分钟，用于体验除批量上传歌曲外的功能。批量上传歌曲是普通用户许可证的付费功能；如需使用请购买普通用户许可证。

### Q: 提示“可信网络时间不可用”
**A:** 可信时间过期或不足时，批量上传歌曲会在安全边界自动刷新；NTP 临时失败会自动重试（最多约 30 秒），重试期间可取消，仍失败才安全收尾。应用不会在两段上传之间插入校时请求。

### Q: 提示“PowerOn 狗号失效”或“PowerOn 认证失败”
**A:** 请确认设置页填写的是恰好 11 位 ASCII 字母或数字。启动页会优先使用当天 07:00 游戏日内的成功缓存；没有可用缓存时暂不开放执行入口。

### Q: 启动后反复显示“PowerOn 认证成功（缓存保存失败）”怎么办？
**A:** 同一游戏日内这不是预期行为。旧安装数据库会自动迁移到新缓存结构并修复不一致缓存表，无需清除应用数据或重填狗号。跨游戏日、变更狗号或缓存校验失败时重新认证是正常现象；若升级后仍持续重复请求，请导出诊断日志反馈。

### Q: 从自定义数据页或批量上传歌曲配置页返回后黑屏怎么办？
**A:** 返回、取消和前台保护丢失都应只退出当前配置页并回到主页面；若当时打开了选择器或提示框会先将其关闭。若仍复现黑屏，请保留操作步骤并导出诊断日志反馈。

### Q: 发票失败
**A:** 可能原因：账号内已存在功能票（应用会自动跳过）、IP 被服务器限制、网络连接问题。

### Q: 存档发送失败
**A:** 可能原因：

- 网络不稳定：正式执行中的可恢复读取失败会自动重试（最多 5 次、约 30 秒），重试耗尽才结束
- 单次或偶发空响应通常只是服务器繁忙，不会判定 IP 被封；只有单个逻辑读取连续多次全部为空才记录疑似软封禁
- 登录、发票、登出、上传等状态变更请求只发送一次，结果未知时不重发，只做安全对账
- IP 地址被封禁

### Q: 扫描二维码不工作
**A:** 请在系统设置中授予应用相机权限。

### Q: 无法安装更新
**A:** Android 8.0+ 需要授予“安装未知应用”权限，应用会在下载完成后提示授权。

### Q: 检查更新/下载失败
**A:** 显示“新版本安装包尚未上传，请稍后再试”表示检查成功但开发者尚未提供 APK，稍后重试即可。若显示具体错误，请先检查网络和当前可用源；更新与公告服务使用应用内配置的源，不需要在系统 WLAN 中为应用配置代理。

### Q: “获取账号数据”中的自定义数据是什么意思？
**A:** 数据获取完成后自动弹出配置页面，可临时修改游玩数据，每个配置项旁显示当前原始值。所有配置仅在本次执行内有效，完成后清除。

### Q: 歌曲成绩上传的“Playlog 真实化”是什么？
**A:** 开启后配置页会按谱面物量准备 playlog 判定：先按 Achievement 与 Combo 生成基础判定，再调整可达判定匹配 DX 分；最终上传直接复用配置页保存的判定值，不在上传前重新求解。关闭真实化时使用旧兼容模板，仍可手动配置判定值。手动填写与自动结果共用同一套上传路径。

### Q: 歌曲成绩上传为什么不能选择同一首歌的同一难度？
**A:** 每份 playlog 对应一条谱面成绩记录，服务器按 (musicId, level) 唯一约束；重复谱面会导致整次上传被丢弃，因此难度下拉会禁用其他行已选的谱面。

### Q: “批量上传歌曲”是什么？和“修改并上传”有什么关系？
**A:** “修改并上传”是“获取账号数据”页的主开关，“批量上传歌曲”是同一卡片内的子开关。主开关关闭时仅获取数据；主开关开启且批量上传歌曲关闭时进入普通自定义配置；两者都开启时进入批量上传歌曲多会话流程。批量上传每批按 3 个短曲额度构建，通过续关在下一会话重新下载完整数据并回验上一批后继续。

### Q: “歌曲成绩清除”会清理哪些成绩？
**A:** 它是批量上传歌曲配置页中的独立互斥操作模式，只处理本账号完整数据中已经存在的 `(musicId, level)`，每条固定写入 `achievement=0`、`comboStatus=0`、`syncStatus=0`、`deluxscoreMax=0`、`scoreRank=0`、`extNum1=0`、`playCount=1`；不为未游玩谱面造记录。LXNS 返回 404 时跳过整首并保留原成绩。

### Q: “修改并上传”开关有什么作用？
**A:** 位于“获取账号数据”标签页，默认开启，是修改上传流程的主开关：开启且批量上传歌曲关闭时进入普通自定义配置并上传；开启且批量上传歌曲开启时进入批量流程；关闭时仅获取数据并登出，不修改存档。

### Q: 日志导出文件在哪里？
**A:** 点击导出会弹出文件选择对话框，导出为 `.txt`，包含本次实际使用的配置/设置/运行状态、操作日志、变更详情、最近 10 批上传载荷和网络诊断详情；LXNS 诊断正文最多采集 10 KiB 并标注截断量。

### Q: 处理过程中可以取消吗？
**A:** 可以。点击**取消**后会在下一个安全检查点停止主业务并尝试登出；登出无法确认时 Session 会保留供下次收尾。批量上传歌曲不会把未通过回验的批次误报为完成，也不会在取消后继续发送下一批。

## 注意事项

1. **二维码时效**：有效期 10 分钟，请及时使用
2. **许可证时效**：创建后 1 小时内必须导入；试用证固定有效 2880 分钟，导入时效不顺延有效期
3. **功能票倍数**：5 倍存在风险，建议使用默认的 3 倍（4 倍和 6 倍自游戏 1.55 起不再支持，已移除）
4. **发票等待**：固定 20 秒，从登录响应成功返回后计时
5. **网络环境**：确保网络连接稳定；更新与公告按应用内配置的源访问，应用不会读取或注入系统 WLAN 代理
6. **机厅配置**：仅手动填写机台狗号（11 位大写字母/数字）；区域、店铺和认证时间来自 PowerOn
7. **时间同步与 PowerOn**：执行前必须拥有新鲜可信网络时间和可用 PowerOn 状态；同步/认证期间不能开始执行
8. **存档修改**：请谨慎使用，配置时登录态保持中，请尽快完成配置
9. **批量上传歌曲任务**：仅普通用户/管理员许可证可用；操作模式互斥（批量上传/成绩清除），按版本或按歌曲选择目标；每批按 3 个短曲额度切分；状态变更请求只发送一次，结果未知或登出无法确认时中断
10. **安全登出**：无论成功或失败都会尝试安全登出；异常退出后下次检测到已登录会自动尝试登出
